# 3D-пластилин (Three.js): кукла на каркасе в настоящем мире

Объёмная пластилиновая кукла — как в советских пластилиновых мультфильмах («Падал прошлогодний снег»), —
снятая будто на живой натуре: кирпич, мокрая брусчатка, фонарь, дождь, туман, глубина резкости макросъёмки.
Пример — «Улика» (10 с): Инспектор Шлёп крадётся по ночному переулку, находит листочек, камера плавно
наезжает — на листке «Алёна какашка»; шок, хитрая ухмылка, приподнял шляпу, фонарь гаснет.

## Открыть / отрендерить (из корня репозитория)

```bash
npm install                                              # three, puppeteer-core
# смотреть: открыть clay3d/index.html в Chrome через локальный сервер (ES-модули не грузятся с file:// в некоторых браузерах)
npx http-server -p 8080 .   # → http://localhost:8080/clay3d/index.html   (?t=5.5 — открыть на 5.5 с)
node render.mjs --page=clay3d/index.html --soft-gl --sheet=1,3,6,8.4 --cols=2 --out=out/check/clay3d.jpg   # контрольные кадры
node render.mjs --page=clay3d/index.html --soft-gl --frames --workers=3 && node render.mjs --page=clay3d/index.html --encode --audio=out/rain.m4a --out=out/clay3d.mp4
```

`--soft-gl` — рендер WebGL без видеокарты (SwiftShader). С видеокартой флаг не нужен. Загрузка страницы
~1 минуту: текстуры кирпича и брусчатки считаются по пикселям при старте.

## Устройство

- `js/tex.js` — процедурные текстуры: кирпич (цвет, нормали, шероховатость), брусчатка с лужами, фактура
  пластилина (отпечатки пальцев, следы стека — bump), листочек с надписью (шрифт Caveat, кириллица, OFL).
- `js/puppet.js` — кукла. Каркас из групп-суставов: таз → бёдра → колени → щиколотки (ноги ставятся
  **обратной кинематикой**: задаёшь, где стоят ступни, колени сгибаются сами); позвоночник → плечи → локти →
  кисти → **5 пальцев, у каждого 3 фаланги и ноготь**, большой палец — 2 фаланги; шея → голова (белки,
  зрачки с бликом, веки для моргания, брови, нос-картошка с ноздрями, румянец, уши, усы, рот трёх видов,
  волосы) → шляпа (залом, поля опущены спереди). Плащ: корпус + отдельная юбка на тазу (качается с
  запаздыванием), пояс с латунной пряжкой, лацканы, воротник, пуговицы. Каждая деталь — «комок»
  с неровностями по шуму. `pose({...})` — все параметры в шапке файла.
- `js/world.js` — переулок в сантиметрах (кукла ≈ 31 см): стена, бордюр, мостовая, чугунный столб,
  водосточная труба, фонарь-прожектор с мягкими тенями, контровой лунный свет, дождь (2600 штрихов),
  брызги, мятый листочек.
- `js/main.js` — таймлайн: поза куклы по 12 перестановок в секунду (стоп-моушен, плюс микро-дрожь
  суставов), камера, свет и дождь — плавно; глубина резкости (BokehPass), перевод фокуса между планами;
  2D-доводка: ореол, зерно, виньетка, мерцание экспозиции.

## Как сделать свой ролик

Скопируй папку, поменяй `poseAt(t)` (игра куклы), `cameraAt(t)` (камера) и `lampK(t)` (свет), реквизит —
в `world.js`. Новых персонажей собирай как `makeDetective`: те же помощники `capsuleDown`, `taperTube`,
`sculpt`, тот же каркас.
